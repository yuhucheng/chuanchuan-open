# 设备恢复期间的断开入口

断线进入认证恢复后，设备可能已从局域网发现中消失。设备场仍按已验证身份保留该节点，并允许打开设备面板取消恢复；取消后该离线节点重新只显示保存资料。恢复期间不提供重新配对的操作入口，避免原授权恢复与新短码连接在同一面板中竞争。

「断开该设备并撤销全部授权」现在按对端公钥撤销活动 grant 和恢复中的 grant，再关闭该设备的连接。活动授权在 socket 清理等待前即失效；其他设备的连接不在此操作范围内。全局「关闭允许连接并断开全部」行为未改。

验证：`flutter analyze --no-pub` 无问题；`flutter test --no-pub` 336/336 通过。定向用例覆盖离线恢复节点可打开/取消后不可打开、活动 grant 立即撤销、恢复 grant 取消，以及反向连接两条会话的按设备断开。以上是本机组件和回环连接证据；两台真实桌面设备的断网恢复、媒体续播及异网首次六码连接仍待验收。
