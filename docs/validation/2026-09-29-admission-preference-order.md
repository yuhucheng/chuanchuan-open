# 允许连接偏好与退出顺序（2026-09-29）

`DesktopLifecycle` 是主窗口隐藏后仍由进程持有的控制器。连接状态变化可能在前一次原生 `state` 调用尚未完成时再次通知；若并发写入托盘/持久偏好，较早的开关值可能最后落地。现把写入串行化，在等待期间仅保留最新值。退出先同步关闭新媒体/连接准入并完成资源清理，再等待退出前已发出的偏好写入，随后才调用原生 `prepareExit`；退出造成的临时关闭不写成下次启动的开关偏好。

定向 `test/desktop_lifecycle_test.dart` 17/17 通过。新增用例让原生“允许连接”写入延迟完成，期间关闭接入并发起退出，验证关闭值最后落地且 `prepareExit` 在其后；修改文件 `flutter analyze --no-pub` 无问题。此用例验证编排顺序，不代替 macOS/Windows 托盘持久化和完整后台实机验收；Windows 完整后台验收仍由 Windows 开发机完成。产品任务 2.4 保持待办。
