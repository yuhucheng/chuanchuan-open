# 全局断开单次清理

托盘与本机面板可能同时要求关闭「允许连接」并断开全部。`ConnectionController.disconnectAll()` 现在在首次调用中同步撤销 grant、恢复尝试和短接码；后续并发调用返回同一个清理 Future，不会重复撤下入口，或在第一轮传输尚未关闭时提前放开接入保护。清理真正结束后才允许用户再次开启连接。进程退出可加入同一个清理 Future。

验证：模拟平台把发现撤下操作保持未完成，确认两次断开共用 Future、只有一次撤下、期间不能重新开启且结束后可以重新开启。真实回环授权测试继续验证调用时立即撤销。客户端 `flutter analyze --no-pub` 无问题、`flutter test --no-pub` 337/337 通过。未执行托盘双击并发、Windows 后台或两台真实设备的网络验收。
