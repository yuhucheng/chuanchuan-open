# 首次跨网会合发起端失败清理（2026-09-29）

六码首次会合的发起端在握手失败或取消后，原流程会立即关闭本地 wire，但可能先向界面返回失败，再由路由异步执行 `/v1/meet/leave`。此时立即重试可能遇到尚未释放的旧尝试。

现在本地关闭仍立即生效；失败结果返回前，支持离会等待的 wire 会加入其路由所有者已有的清理 Future。等待最多两秒，网络失联仍由服务端租期回收。取消发生在打开 wire 期间时，迟到的 wire 也按同一顺序清理。普通本地 TCP wire 不增加远端等待。

验证：连接包 `dart analyze` 无问题、完整 `dart test` 93/93；客户端辅助路由与连接控制器定向 `flutter test --no-pub` 20/20，修改文件 `flutter analyze --no-pub` 无问题。新增用例延迟远端清理，确认失败和迟到取消均在本地关闭后等待清理再返回。

证据仅覆盖本地协议与控制器行为。官方辅助服务仍未上线；陌生异网双机、真实媒体路径及目标环境容量验收仍待完成。
