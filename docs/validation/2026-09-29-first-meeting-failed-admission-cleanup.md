# 首次跨网会合失败接入的离会清理（2026-09-29）

首次六码会合的被接入端若在握手中遇到错误，原实现立即关闭本地 wire，但接入任务未等待已发出的 `/v1/meet/leave`。随后切换辅助服务或退出时，清理屏障可能先结束并关闭 HTTPS transport，使服务端待接入项只能等短租期回收。

现在失败接入立即关闭本地 wire，并在从接入任务与路由清理屏障移除前等待离会结果。网络失联仍使用原有两秒上限，不能阻塞本地撤销；服务端租期仍是最终回收保障。成功建立的会合连接继续由当前路由所有者管理，不因关闭短码接入而断开。

验证：`packages/share_hub_connection` 的会合定向测试 11/11、完整 Dart 测试 91/91、修改文件 `dart analyze` 通过。新增用例延迟服务离会响应，确认失败接入的路由关闭会等待该响应。本结果只覆盖本机模拟传输，不证明线上服务、真实异网双机、媒体 selected pair 或 0.1.0 整体验收。
