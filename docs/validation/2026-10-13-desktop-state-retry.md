# 后台状态写入恢复 — 2026-10-13

修复客户端后台偏好写入失败后无法通过设置重试、成功后仍保留旧错误，以及晚到写入错误覆盖退出清理故障的问题。属于桌面 change 7.1 与场式客户端 2.4/3.1 的实现补充；跨平台实机任务仍待验收，不新增完成勾选。

## 行为

设置在后台状态写入失败时提供「重试后台状态」。重试仅重新提交当前「允许连接」值；并发点击加入同一写入 Future，不关闭连接、重新开监听或更新短接码/授权。正常连接状态变化仍串行合并到最新值，仅最新写入成功时清除自己的错误。

初始化、后台状态与退出各自保留错误，退出清理故障优先显示；晚到的状态回复不能覆盖或清除退出错误。退出/已退出/销毁及初始化未成功时不提供该重试入口。原退出清理、10秒有界等待及未完成所有者保留规则不变。产品0.1.0、开发SDK0.1.0-dev.1、公共媒体API0.8.0、会话协议2、grant扩展类型/时长与当前八小时策略不变。
