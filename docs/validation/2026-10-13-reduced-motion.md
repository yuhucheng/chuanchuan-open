# 场式界面减少动效

系统启用减少动效后，主题切换即时生效，设置、本机工具、设备动作和六位短接码弹窗不再执行开关过渡；普通偏好继续使用 Flutter 默认时长。主题更新保持原有 AnimatedTheme 和页面状态所有者，实时切换辅助偏好不会重建设备场、丢失搜索输入/焦点或启动媒体采集。

修改仅涉及客户端 UI。连接授权、六位短码及当前八小时策略、公共媒体 API、SDK 和平台宿主没有变化。

## 验证

Flutter 3.47.2 / Dart 3.13.2：

- 新增三项组件测试覆盖正常/减少动效的四种弹窗，Escape 取消返回，以及运行中切换系统动效/主题后的输入、焦点和页面状态保留；来源查询和采集启动计数保持零。
- 测试夹具调整完成后，在此前提交的三个生产文件上验证：普通偏好用例通过，减少动效弹窗时长仍为 150ms、系统主题切换未即时完成的两项负例失败；恢复新实现后定向组件和键盘回归 14 项通过。
- 完整客户端测试 336 项通过、1 项 Windows 专属跳过；静态分析无问题，普通 Mac Debug 构建通过（应用未启动）。完整工作区包含其他会话的未提交设备命名修改，属于当前工作区观察证据，不作为可复现发布组合。

未启动原生应用、执行 OS 来源枚举/采集、实际读屏或双机。Windows 构建及其平台矩阵仍由 Windows 开发机负责。任务 3.1 的平台对比、读屏和完整可达性尚未全部验证，此次不将整体任务标为完成。
