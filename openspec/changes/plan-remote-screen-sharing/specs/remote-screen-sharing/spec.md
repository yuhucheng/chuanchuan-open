# 远端屏幕共享

## Purpose

将既有设计中的远端屏幕共享整理为可审阅的未来行为契约。当前能力尚未实现，本次仅迁移规格；规格版本独立维护，目标版本只说明规划归属，不代表已经授权开发、完成验收或承诺发布日期。

## ADDED Requirements

### Requirement: 明确来源和对端

屏幕共享 MUST 在用户明确选择来源、可信对端及所需观看授权后启动；刷新或来源失效不得静默切换到整块显示器。

#### Scenario: 来源在连接中关闭

- **WHEN** 用户选定窗口后，该窗口在会话启动前消失
- **THEN** 报告来源不可用并等待重新选择，不改采默认屏幕。

### Requirement: 独立观看能力

会话 MUST 协商实际发送与观看能力，独立于远控授权；不支持的媒体版本或能力必须返回明确状态。

#### Scenario: 只获观看授权

- **WHEN** 对端已获观看能力但没有控制授权
- **THEN** 可以按约定观看画面，输入控制请求仍被拒绝。

### Requirement: 真实远端状态

界面 MUST 区分连接中、等待对端首帧、正在共享和失败；只有对端实际接收并呈现所选来源画面后才能声称远端投屏成功。

#### Scenario: 本地预览有帧而对端无帧

- **WHEN** 本地来源预览成功，但对端首帧始终未到达
- **THEN** 保持等待或进入首帧失败状态，不显示投屏成功。

### Requirement: 停止与权限变化

共享会话 MUST 在用户停止、采集许可失效、来源结束或会话实际断开时终止相关采集和发送，并释放资源；重连不得沿用失效的观看或控制授权。

#### Scenario: 共享期间撤回采集权限

- **WHEN** 发送端系统撤回录屏权限
- **THEN** 停止采集和发送，通知对端结束，不继续保留虚假的共享状态。

### Requirement: 异步取消与会话隔离

启动与重连 MUST 可取消，旧会话回调不得结束或恢复新的会话；清理失败必须可见且不得显示已完全停止。

#### Scenario: 旧首帧回调晚到

- **WHEN** 用户取消会话后又建立新会话，旧首帧回调到达
- **THEN** 忽略旧回调，仅当前会话的实际画面可更新状态。

## Verification

- 在 Windows/macOS 两端分别验证发送和观看，记录所选窗口/显示器可辨识内容、真实对端首帧及停止后不再更新。
- 覆盖直连和中继、权限撤回、来源关闭、取消与断线；性能阈值和音频范围待确定。
- 当前 PreviewEngine 仅为本地接口，尚不能提供以上完整会话。

所有场景均为待验收项；现有单元测试、局部平台构建与媒体实验不构成本能力已经交付的证据。
